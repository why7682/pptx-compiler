# M2-005 Reviewed Profile-Induction Evidence

## Scope

This is a bounded public-synthetic effect experiment, not automatic semantic
understanding or a product support claim. It tests whether exact facts from
several visually different source exemplars can be separated from human review,
then used to select and assemble the source composition that matches a slide
brief.

No source wording, font name, PPTX, PNG, raw review report, prompt transcript,
or renderer output is committed. All source archives are generated at runtime
from the repository-owned text-only OOXML fixture. macOS Quick Look remains an
optional local compatibility oracle, not a CI requirement.

## Authority boundary

`labs/layout-selection/reviewed-profile-induction.mjs` executes five distinct
phases:

1. securely admit and snapshot every source archive plus its exact
   `TemplateIndex`;
2. emit a redacted proposal containing only geometry, normalized region,
   source order, font size, bold/alignment facts, deterministic salience rank,
   and a geometry/type-size capacity estimate;
3. bind a complete accepted-or-rejected review decision to every proposal and
   to the proposal-set SHA-256;
4. admit only reviewed profiles with a clear hierarchy, one primary takeaway
   slot, one supporting-evidence slot, primary type of at least 24 pt,
   supporting type of at least 18 pt, and reviewed capacity no larger than the
   inferred ceiling; and
5. select across the accepted sources, then pass only the winning exact
   source/index/profile through the existing atomic clone/fill assembly API.

The source-derived `suggestedRole` is non-authorizing. The committed text-only
review fixture at `fixtures/profile-induction/reviewed-acceptance.json` freezes
the proposal-set and per-proposal hashes. A source-fact or induction-algorithm
change therefore invalidates the old review rather than silently rebinding it.

## Distinct synthetic exemplars

| Exemplar | Exact visual facts | Review decision | Admitted use |
| --- | --- | --- | --- |
| `decision-focus` | 44 pt bold upper primary; 20 pt lower support | accepted | decision takeaway as text; evidence as metric |
| `status-focus` | 48 pt bold upper primary is the second source shape; 24 pt lower support is the first source shape | accepted | status takeaway as metric; evidence as text |
| `ambiguous-balance` | two equal 28 pt regular boxes | rejected: ambiguous hierarchy | none |

The second accepted exemplar proves that visual rank is not confused with
source order. The rejected exemplar proves that a deterministic tie-break may
describe facts but cannot create semantic authority.

## Three isolated visual runs

All three reviewers marked the inputs assessable, judged the desired audience
outcome `met`, and agreed that each selected source makes its intended takeaway
the immediate first read while preserving readable support. The executable
aggregator returned `status: final`, `verdict: pass`, and no retained finding.

One run reported a minor top-heavy concern on the status slide. The required
bounded contradiction follow-up dismissed it: the visible headline occupies
approximately normalized y `0.255–0.337`, the supporting line `0.688–0.721`,
and the reported region ending at y `0.22` contains neither line. No repair was
authorized from that unsupported finding.

The visual result does not prove native editability, accessibility metadata,
font embedding, animation behavior, arbitrary-template compatibility, or
PowerPoint support.

## Conclusion and next dependency

The borrowed mechanism now works across real, distinct source compositions:
exact source facts remain separate from review; review remains stale on source
drift; deterministic selection changes which authentic visual hierarchy is
assembled; and real renders show the intended message first.

The next dependency is the ordered multi-slide graph in M2-005B. It must retain
this source-facts → reviewed semantic profile → deterministic selection →
atomic assembly boundary while adding complete-batch slide and relationship
allocation.
