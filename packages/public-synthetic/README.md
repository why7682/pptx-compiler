# pptx-compiler-public-synthetic

## Purpose and boundary

`pptx-compiler-public-synthetic` is the zero-dependency `0.1.0-alpha.2`
repository-owned conformance preset. It is a public test input, not a production
template catalog or evidence for user presentations.

## Fact ownership and dependency flow

This package owns reviewed text-derived POTX source parts, expected inspection
facts, and the exact project preset. It imports no other alpha package and owns
no compiler, executor, support decision, or delivery authority.

## Executable contract

The CLI resolves these installed resources explicitly and binds them to the
exact template profile and expected index. Substitution, ambient discovery, and
private fixture fallback fail closed.

## Evidence

The [reproducibility procedure](https://github.com/why7682/pptx-compiler/blob/main/docs/REPRODUCIBILITY.md)
uses this preset in public tests. Passing those tests proves only the exact
public-synthetic path.

## Limitations

The package contains no private presentation, user template, renderer,
capability executor, generic fixture corpus, or compatibility promise.
